## 仍未交付

### P1 余项 · 单张修图

- 白平衡吸管：点取中性灰或白色区域，给出色温和色调，再用滑杆细调。
- 高光／阴影剪切提示：可在画布上开关，标出当前成片的过白和过黑区域。
- 三向色轮：用色轮控制阴影、中间调、高光的色相和饱和度，保留数字输入。

### P2 · 风格、选片和批量交付

- 黑白混色、胶片颗粒和暗角：独立保存参数，便于同一款胶片色调搭配不同质感。
- 扩展风格导入：HaldCLUT PNG；可录入玩家配方并映射成可调参数。社区转换风格标注为近似效果。
- Lightroom／Camera Raw 预设导入：先映射曝光、曲线、HSL 等有对应控件的 `.xmp` 字段，并列出未映射项。
- 点色：在画布上取样并调节颜色范围。
- 命名版本：同一张照片保存并切换「自然色」「胶片暖调」等版本。
- 照片多选和筛选：星级、入选／淘汰标记。
- 按组同步调整：多选照片后按组同步基础调色、曲线／HSL、风格；构图、蒙版和人像框选仍各自管理。
- 画布内污点修复：灰尘、痘印和小杂物。
- 抠图和透明导出：主体蒙版、手动修边、换背景、透明 PNG。

### P3 · 按实际素材安排

- 更多局部工具：笔刷、橡皮、亮度范围、颜色范围，以及蒙版相加／相减／交集。自动天空、主体和对象选区用实际照片验证后再定。
- 镜头与透视：手动畸变、紫边、透视校正；自动镜头校正按机身、镜头和配置数据逐项验证。
- 人像细化：眼袋和黑眼圈、眼白、牙齿，以及手动液化。接入前用不同肤色、光线和构图的样片验收。
- 光谱胶片与相纸模拟：先评估 Windows 渲染、配置和资源授权。
- 多张合成：HDR 包围曝光、全景拼接。
- 可选输出和 AI 工具：输出锐化、水印、元数据、联系表 PDF；按需接入局部重绘、超分和低清人脸修复。

## 交付前要先修的工程项

2026-11-14 逐项复核：前三项已在 0.8–0.10 修完，第四项的导出侧本轮完成。

- 导出目标保护已于 0.8 统一：JPG／PNG／TIFF／PSD／Patchy 都先经过同一套路径检查，`tests/export_protection.rs` 覆盖删除源路径和 evicted 别名。
- `legacy_blur` 的 u8 量化只保留在 8 位兼容管线；16 位和浮点导入走 `float_blur`（`src/core/adjustments.rs:24`）。
- 批量导入容量预检、切图与换风格时的预览取消、RGB 直方图和像素读数均已落地（`src/core/diagnostics.rs`、`src/ui/diagnostics.rs`）。
- 输出色彩空间已完成：JPG／PNG／TIFF 可选 sRGB、Display P3、Adobe RGB、ProPhoto RGB，并写入对应 ICC（`src/core/colorspace.rs`、`tests/export_colorspace.rs`）；PSD 与 Patchy 固定 sRGB。工作缓冲仍是 float32 sRGB，超出目标色域的部分会裁剪。

仍未做：广色域工作缓冲、逐显示器校色。

## 验收场景

| 场景 | 通过条件 |
|---|---|
| 风景局部调色 | 用一张真实 RAW 压低天空高光并保住地面。蒙版边缘可预览，重开后方向、羽化和数值一致。 |
| 人像局部调色 | 用羽化径向蒙版提亮面部，背景保持原有明暗。与已有皮肤修饰可分别调整。 |
| 构图和输出 | 裁剪并拉直后，画布和 JPG／TIFF 输出构图一致。工程重开后仍可修改裁剪。 |
| 批量交付 | 将基础调色和 LUT 同步到一组照片，各自的构图和局部调整单独保留。批量导出每张成片并报告失败项。 |
| 旧工程兼容 | 0.3 工程可以重开。缺省的新参数按中性值处理，同样的旧设置保留原来的渲染结果。 |
